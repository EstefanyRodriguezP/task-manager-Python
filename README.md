# 📝 Task Manager - Python CLI App

Este proyecto es una **aplicación de línea de comandos** desarrollada en Python que permite gestionar tareas de manera sencilla y funcional desde la terminal. Fue desarrollado como parte del bootcamp de **Desarrollador Full Stack Python Trainee**, aplicando conceptos fundamentales del lenguaje.

## 🎯 Objetivo

Construir una herramienta ligera y práctica para organizar tareas diarias sin depender de interfaces gráficas, ideal para cualquier entorno donde esté disponible Python.

## ⚙️ Funcionalidades

El gestor de tareas permite al usuario:

1. **Agregar una nueva tarea**
2. **Ver todas las tareas**, indicando su estado: `Pendiente` o `Completada`
3. **Marcar una tarea como completada**
4. **Eliminar una tarea**
5. **Salir del programa**

Todas las tareas se guardan de forma persistente en un archivo (`tasks.txt`), asegurando que no se pierdan entre sesiones.

## 🧠 Tecnologías y conceptos aplicados

- Python 3
- Estructuras de datos: listas y diccionarios
- Funciones reutilizables
- Manejo de archivos (`open`, lectura y escritura)
- Validaciones de entrada
- Control de flujo (condicionales y bucles)

## 🖥️ Ejemplo de uso

Al ejecutar el programa, se presenta un menú interactivo como este:

--- Gestor de Tareas ---

1. Agregar tarea
2. Ver tareas
3. Marcar tarea como completada
4. Eliminar tarea
5. Salir

Cada acción se ejecuta según la opción elegida, y luego se vuelve al menú principal hasta que el usuario decida salir.

## 🚀 Cómo ejecutar

1. Clona este repositorio:

```bash
   git clone https://github.com/EstefanyRodriguezP/task-manager-Python.git
   cd task-manager-Python
```

2. Ejecuta el programa con Python:

```bash
python main.py
```
